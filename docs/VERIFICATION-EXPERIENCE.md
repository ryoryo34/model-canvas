## Reproduce / 再現

```sh
npm run typecheck
npm test
npm run test:e2e  # builds and runs all 18 browser tests
# If 4312 is busy / 使用中なら:
MODEL_CANVAS_TEST_PORT=14336 npm run test:e2e
npm run dev -- --port 14335
```

The existing lockfile dependencies and installed Chromium were reused; `npm ci` was not repeated. E2E owns and closes its 4312 demo server and random-port shared processes; it never stops existing previews. / 依存再インストールは未実施。自分のE2Eプロセスだけ終了。

## Limits / 制約

- Local verification only: no live LLM, paid API, Codex/Claude host configuration, deployment or merge. Safari, Firefox, physical mobile devices, large models and other operating systems are unverified. / 実LLM・ホスト設定・他ブラウザ・実機モバイル等は未確認。
- Fit can make text small on phones or large layouts; use 100% and internal scrolling. Fit is view state, not persisted zoom. / 小さな文字は100%で確認。倍率は保存対象外。
- Navigation retains mounted forms in memory, appropriate for the existing small-model scope. Drafts are not persistent history: browser reload, explicit shared reload, imports, JSON commands that rebuild editors, and record/field schema changes can reset affected inputs. Hidden shared drafts intentionally keep synchronization paused until applied or explicitly discarded. / 選択移動は保持、永続履歴ではありません。
- Existing import behavior remains: fix missing source-record references before reimporting an export. Required/type-invalid samples remain importable. / 元のimport制約を維持。
- No independent feature or separate existing acceptance failure was confirmed during this verification. The first E2E run found one selector matching both visible and retained hidden records; it was updated to inspect the visible record. / 別Issue相当の不具合は今回の確認では未発見。
