# Model Canvas

[English](./README.md) | [日本語](./README.ja.md)

AIと人が一緒に、モデル・関係・制約をサンプルデータで試せる設計キャンバス。

## 開発状況

開発初期です。現在は企画とIssue駆動の開発方針を収録しており、最初の動くデモを専用Issueで実装します。構想段階の機能はまだ使えません。

## 開発

[構想](docs/VISION.md)、[開発フロー](docs/WORKFLOW.md)、[Issue](https://github.com/ryoryo34/model-canvas/issues)を参照してください。1 Issueにつき1つのCodexセッションと実装ブランチを使います。起動手順は動くデモとともに追加します。
